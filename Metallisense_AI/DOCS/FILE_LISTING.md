- GREY-IRON (Grey Cast Iron)
- LOW-CARBON-STEEL
- MEDIUM-CARBON-STEEL
- HIGH-CARBON-STEEL

### AI Agents (2 Agents)

   - Severity levels: LOW, MEDIUM, HIGH
   - Normalized scores: 0-1
